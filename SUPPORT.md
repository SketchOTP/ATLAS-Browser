# Support

Use the repository's GitHub features according to the type of request:

- [Discussions](https://github.com/SketchOTP/ATLAS-Browser/discussions) for setup questions, ideas, and usage guidance
- [Issues](https://github.com/SketchOTP/ATLAS-Browser/issues) for reproducible defects and scoped feature requests
- [Private vulnerability reporting](https://github.com/SketchOTP/ATLAS-Browser/security/advisories/new) for security concerns

Before filing a defect, use the latest supported release, reproduce it with a temporary `ATLAS_USER_DATA_DIR`, and include the operating system, ATLAS version, selected provider, expected result, and observed result. Remove tokens, cookies, private URLs, profile data, and personal documents from logs or screenshots.

ATLAS is maintained as an open-source project. Response times are not guaranteed.
